Want a catalog like this, for your own collection?

This system started from one written request to Claude, then grew in stages — a live pricing feed, nightly backups, a daily integrity check — with every irreversible step held for approval along the way. Below is a version of that starting request you can copy, adapt to your own collection, and paste into a new Claude conversation. 

I want to build a personal catalog for my collection (records, books, watches, wine, sneakers — whatever I actually track), with a running estimate of what it's worth.

Here's the pattern I want it to follow:
1. Start from whatever list I already have, however messy, and help me turn it into a clean, structured record — one field per attribute that actually matters (condition, year, what I paid, current value).
2. Pull live market prices on a schedule from a real source for my category (a marketplace's sold listings, an auction index, whatever fits), so the value stays current without me pricing anything by hand.
3. Publish it as a small, real website I can check from my phone.
4. Back the whole catalog up automatically every day, somewhere separate from the live copy — so a bad edit or a broken deploy costs a day, not the collection.
5. Run a daily check that only reads and verifies — record count, prices present, backup landed — and tells me plainly if anything's wrong, without ever having the authority to fix it itself.
6. Treat any bulk delete or destructive edit as something that always needs my explicit yes, no exceptions.

Please help me scope this into a first small version we can finish today, tell me exactly what you'd need from me at each step (any account access, any purchase like a domain name, anything you can't do without my say-so), and don't do anything irreversible without checking with me first.

Worth knowing before you start

This catalog has recovered from two real failures — a bad edit and a broken deploy — both within a day, because the backup and the daily check already existed before they were needed. Build both from the start; they're the cheapest insurance in the whole system.
