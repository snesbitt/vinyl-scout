# Vinyl Scout

Susan's personal vinyl record cataloging app. Single-user, hosted on Netlify at vinylscout.org.

## Scope

Catalog (Phase 1), Discogs enrichment (Phase 2), wishlist (Phase 3), and audio preview (Phase 4) are all live. See `PROJECT.md` for the canonical charter, hard rules, and what is and is not in scope. `PROJECT.md` is the source of truth. This README isn't.

## Deploy

Push to `main`; Netlify auto-deploys.
